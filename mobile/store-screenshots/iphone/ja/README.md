# iPhone版・日本語スクリーンショットの元画像

現在のアプリをiPhone 16で撮影した、無加工のPNGをこのフォルダに保存しています。
`app-store-plain/` は提出形式に合わせてアルファチャンネルを除いた複製です。
デザインプレビューやオンボーディング用の合成画像は、実画面の代わりに使用していません。

| ファイル名 | 撮影する画面 |
| --- | --- |
| `01-home.png` | ホーム（残り予算が見える状態） |
| `02-expense-entry.png` | 支出入力（金額とキーボードが見える状態） |
| `03-calendar.png` | カレンダー（日ごとの支出が見える状態） |
| `04-graph.png` | グラフ（月のやりくりが見える状態） |
| `05-monthly-budget.png` | 新しい月度の予算設定 |

- 個人情報を含まないテストデータで撮影してください。
- 画像は元の解像度のまま保存してください。iPhone 16の縦画像は1179×2556ピクセルです。
- 5枚とも1179×2556ピクセルの実機キャプチャです。
- `app-store-plain/` は実画面に装飾や文言を加えない版です。マーケティング見出し付きの版は別途制作します。
