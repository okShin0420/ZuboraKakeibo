# ホームモック：参考と判断

## 参照固定（2026-09-21）

- 仕様の優先順位：最新のユーザー指示 → DESIGN.md → README.md のプロダクト原則。
- 主参照：[image.png](image.png)。淡いピーチのキャラクターエリア、立体的な毛並み、白い余白、濃い文字、淡いブルーの補助カードを採用。検索・特典・保険など参照アプリ固有の機能は持ち込まない。
- 犬のモデル：[jikkun.jpg](jikkun.jpg)。黒い毛、垂れ耳、グレーの口元、青緑のしましま服を専用3D風素材に反映。
- 旧オレンジ案は採用しない。芽・植物・1日あたりの目安は表示しない。
- ユーザー提供の具体的な参考画像で方向が確定しているため、別方向の案は追加しない。Refero の参考優先・配色役割・可読性・操作領域の指針で実装を確認する。

## 判断記録

- 主役は金額。犬はカード上半分に収め、直下の残り予算を最も大きい文字で表示。
- ピーチと白を土台に、犬の服とつながる深い青緑をCTAと選択色に採用。参考画像の紫はそのままコピーせず、犬との色のまとまりを優先。
- 残り日数は中立的なラベルにし、進捗バーや成績評価は設けない。
- 吹き出しは犬の上中央に「今日も、自分のペースで。」。参考の小さな吹き出しを日本語の読みやすいサイズへ調整。
- 犬の頭部・胴体を同じ透過素材のCSSマスクで分離し、頭だけを小さく傾ける。閉眼素材は目の周辺だけを重ねてまばたきさせる。
- ヘッダー中央に当月、右に設定を置き、左のアカウントアイコンと月の選択操作は設けない。
- 設定アイコンはボトムシートを開き、下部タブではホーム、カレンダー、グラフを切り替える。
- 支出入力はホーム上のボトムシートとし、背景操作を抑止する。短い画面・拡大表示ではシート内スクロールを許可し、内容を切り捨てない。

- ピンクとイエローは犬の背景に淡く残し、主役のグリーンを弱めない。

## 犬の服に合わせた配色更新

- 主参照：実装済み犬素材のターコイズ色の服と生成り色のボーダー。
- 保持：白いカード、情報階層、黒い犬の視認性。
- 配色の役割：深い青緑はホーム最上部、明るいアクアは犬の背景、淡い青緑は白へつなぐ中間色に限定する。
- 犬の服と背景が同化しないよう、背景は服より明るく低彩度にし、生成り色の光を狭い装飾用途で加える。
- 操作色：ホームの入力ボタン、今日の支出アイコン、下部ナビゲーションアイコンは `#1E90FF`。本文・数値は黒とし、背景色と役割を混在させない。
- 数値書体：全画面で `Ebrima` を使用する。ホームの主要数値は太字にしない。
- グラフの動き：画面遷移時のみ棒を下から上へ順に立ち上げ、短く機能的な動きにする。年表示は枠の縦方向中央に置き、動きを減らす設定では静止表示にする。
- アイコン：ホーム右上の設定、ホームの「今日つかった」、下部ナビゲーションのカレンダー、設定内の「今月使える金額」は、確定済みのアウトラインSVGを使う。
- 画面間の連続性：グラフ画面の背景はホーム画面と同一のグラデーションを使う。
- グラフ画面：現在のホームを主参照に、白い浮遊カード、`#1E90FF` の棒、黒い文字と年送り矢印を使う。年表示は2026年を初期値とし、1月から12月を暦年順に並べる。
- 支出入力ボトムシート：ホームの白・ターコイズ・`#1E90FF`・黒の役割を継承する。上部中央の小さなタイトル、枠のない中央金額、メモ、保存だけを置き、金額タップ時のみ専用キーパッドを展開する。説明、必須・任意表示、装飾アイコンは置かない。
- 下部タブバー：コンテンツ上に重なる固定レイヤーとし、半透明の白、18pxの背景ぼかし、薄い上境界を使う。3項目は均等幅で列全体をタップ可能にし、選択中のアイコンとラベルだけを `#1E90FF` にする。
- カレンダー画面：ホームとグラフのターコイズ背景、白い浮遊カード、黒い文字、`#1E90FF` の選択状態を継承する。2026年9月を初期表示し、月送り、日別合計、選択日の支出リスト、金額編集に機能を絞る。選択日カードでは合計を表示せず、各明細を主情報として表示する。設定した月初め・月締めの対象期間外はグレースケールで無効化し、月またぎにも対応する。
- ホーム残高カード：白い残高エリア上部に淡い青緑の塗りつぶし肉球を少数配置し、見出し・金額・残り日数とは重ねない。
- 設定画面：ホームの背景・白い浮遊面・黒い文字・`#1E90FF` の操作色を継承する。予算への導線を先頭に置き、通知、月初めの日、締め日、土日祝調整を短いグループへ整理する。
- 今月使える金額設定：犬の短い案内、中央の金額入力、保存だけに絞る。内側カード、説明、金額候補は置かず、保存後は設定へ戻ってホームの残り予算へ即時反映する。
- 設定と金額設定はホームを背面に残すボトムシートとし、見出しと小さな閉じる操作を白いシート上部へ置く。期間ラベルはカード外、月初め・月締めのセレクトは同幅にする。
- 金額設定の入力は専用キーパッドで行う。中立グレーのキーパッドに白い数字キー、上段の金額ショートカット、右下の削除キーを置き、全削除時は0を表示する。円表記と金額横のクリアボタンは置かない。

## グラフ参照ロック（2026-09-25）

- 主参照：ユーザー提供の金融グラフ画面。強い色のサマリー領域、白い分析面、細い丸い縦棒という情報階層を採用する。
- 保持：ターコイズ背景、`#1E90FF` と調和する青系のデータ色、年送り、12か月のグラフ、Ebrimaの数値、下部ナビ。
