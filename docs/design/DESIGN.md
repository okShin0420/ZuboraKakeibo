WebモックとReact Native版は同じ画面方針を共有します。React Native版の金額・支出・設定は端末内SQLiteへ保存し、画面へ反映します。Webモック固有の表示・操作と異なる部分は、実機確認を経て調整します。

## iOS起動画面

- DB接続・初期化・移行などで起動に失敗した場合もスプラッシュを閉じ、白背景に読み込みエラーと「もう一度読み込む」を表示する。再試行ではDB接続を開き直し、保存データを自動削除しない。文字拡大時も案内と操作が読めるようスクロール可能にする。
- 設定の「土日祝の自動調整」の直下に、同梱祝日の対応年（2025〜2027年）と、2028年以降の未収録年は土日のみ調整する旨を表示する。公表後に同梱データと対応年の説明を更新する。

- アプリの起動中に表示するネイティブ画面は全面 `#017AF4` の単色とする。文字・犬・装飾は置かない。説明画面ではなく、初回だけに限定しない。
- 画面内容の読み込み完了と最短0.5秒の表示を満たしたら、起動画面を約0.28秒でフェードアウトし、初回説明・金額設定・ホームのいずれかへ進む。動きを減らす設定ではフェードを省く。起動画面には閉じるボタンを置かない。開発版の設定画面から開くプレビューも0.5秒の表示後に同じフェードで自動的に戻り、データを変更しない。

## ホーム画面

- 犬のキャラクターは確定。
- ホーム背景に限り、指定の青空と桃色の雲の画像を使用する。画像レイヤーだけを軽くぼかし、下部は白へフェードさせる。カレンダー・グラフの背景には適用しない。
- 犬の背後は空をそのまま見せ、ガラスの輪郭は置かない。犬の足元を、上端が緩やかに弧を描く一枚の白い残り予算カードに重ねる。残り予算カードの横幅は「今日つかった」カードと入力ボタンに揃える。カード上端を犬側へ伸ばしても、金額・残り日数・カード下端の位置は維持する。曲線とカード本体を別の図形で継ぎ足さず、一続きの輪郭として描く。足元の影は横長で端がぼける楕円にする。カードは四隅を丸め、肉球の装飾は置かない。残り日数の下からカード下端までに余白を取る。
- React Native版では犬と吹き出しの領域の高さを画面高に合わせて調整し、吹き出しと犬の頭を重ねない。残り予算カード・今日の支出・入力ボタンは順に配置し、下部タブバーに隠さない。文字の書式は維持する。
- ホームの犬はWeb版とReact Native版で、ゆっくりした呼吸・軽い首かしげ・短いまばたきを表現する。React Native版では画像を先読み・共有キャッシュから表示し、端末のモーション低減設定でアニメーションを停止する。
- 犬のキャラクターから吹き出しでコメント
- コメントは月度予算に対する残額割合と残り日数で切り替える。残額80%以上／60〜79%／30〜59%／9〜29%／0〜8%と、残り25日以上／15〜24日／5〜14日の組み合わせを以下の表に従う。80%以上かつ25日以上は「今日も、自分のペースで。」で固定する。
  | 残額 | 25日以上 | 15〜24日 | 5〜14日 |
  |---|---|---|---|
  | 80%以上 | 今日も、自分のペースで。 | まだまだ余裕があるね。 | このままゆったりいこう。 |
  | 60〜79% | いい感じのペースだね。 | この調子でいけそう。 | 月末までいい感じにいけそう。 |
  | 30〜59% | 使い方を少し振り返ってみよう。 | 残りの日数も見ておこう。 | 月末までは少しゆっくりね。 |
  | 9〜29% | まだ先は長いよ。出費を抑えよう！ | このままだと足りないかも。 | 月末まで持つか、確認しよう！ |
  | 0〜8% | もう残りわずか！今すぐ確認しよう。 | 残りわずか！必要なものだけに。 | ほとんど残ってないよ。出費に注意！ |
- 表の範囲外は、予算未設定なら「今月の金額を設定してね。」、残り4日以下なら「今月もあと少し。自分のペースで。」と案内する。残額がマイナスの場合は0〜8%の文言を使う。
- 犬のキャラクターの下に今月の残金
- 残金の下にメーターは表示しない。
- 残金の数値の下に余白を取り、「今日つかった」カードと入力ボタンは少し下へ配置する。小さい端末でも下部タブバーに隠さない。
- 残り日数は残金の数値の下に、背景なしで「残X日」と中央揃えにする。「残」「日」は日数の数字より小さくする。「今日つかった」と支出額はその下の横幅いっぱいの白いカードに配置し、文字の左に青い円形の財布アイコンを置く。カードに外枠線は設けず、柔らかい影で背景から区別する。
- キャラクターと残金の表示はカード形式
- 上部中央に当月を不透明な白文字で、右上に設定アイコンを表示する。アカウントアイコンと月選択操作は設けない。
- [入力する]（プラス記号なし。青い丸角ボタンに「今日つかった」カードと同じ柔らかい影を付ける）
- [入力する]から支出入力ボトムシートを開く
- 下に、[ホーム]、[カレンダー]、[グラフ]を表示

## 設定画面

- ホーム右上の設定アイコンからボトムシートを開き、閉じるボタンまたは背景タップでホームへ戻る。
- 「アプリについて」にプライバシーポリシーの行を置く。選択すると同じシート内でオフラインの本文へ切り替え、戻る操作で設定一覧へ戻す。長文はシート内だけスクロールし、文字拡大とスクリーンリーダーでも読めるようにする。
- データ欄の末尾に `#F30100` を背景とした白文字の「全データを削除」を置く。予算・支出・メモ・設定・説明完了状態・アプリ内自動バックアップの削除対象と取り消せないことを確認ダイアログで示し、確定後は説明1へ戻る。外部に保存したバックアップファイルは対象外と明示する。
- React Native版の予算と1件の支出の入力上限は7桁（9,999,999円）とする。ホーム・設定・初回／新月度設定・支出入力／編集・カレンダー・グラフの金額表示は利用可能幅で文字を縮小し、横方向に欠けないようにする。複数支出の合計や過去データは7桁を超える場合も表示する。
- 最上部に「今月使える金額」と現在値を配置し、専用の金額設定画面へ進める。
- 月初通知と土日祝の自動調整は、カプセル型トラックと円形サムを持つ `role="switch"` で切り替える。
- 月初通知はON/OFFのみ設定でき、時刻は9:00固定とする。端末の通知が許可されていない場合は設定画面に案内を表示する。
- 月度の開始日はホイール選択シートで設定する。初期値は1日とする。
- 月度の開始日は1〜31日から選び、存在しない日付は月末へ丸める。土日祝調整で開始日が前倒しされた場合は、次月度の調整済み開始日の前日を前月度の終了日にして空白を作らない。開始日直下には当月度・次月度の範囲を2行で表示する。
- 開始日・土日祝調整の変更は保存済みの過去・現在・将来すべての月度へ同じ規則で反映する。新しい境界で今日が前月度に入る場合は、範囲プレビューとホームの月度・金額も前月度へ切り替える。
- 土日祝の自動調整がオンの場合、月度の開始日を直前の平日へ調整し、調整結果を範囲表示へ即時反映する。
- 設定画面を行き来しても、操作中の設定値を保持する。
- 設定画面と今月使える金額設定画面は、ホームの上へ重なるボトムシートとして表示する。見出しと小さな閉じるボタンは白いシート内の上部へ配置する。
- 月度の開始日は専用アイコンとホイール選択シートで設定する。月締め日の入力は設けない。
- 今月使える金額設定画面にも右上の閉じるボタンを配置する。金額の「円」と隣のクリアボタンは表示しない。
- 画面を開いた時点で下部へ専用の数値キーパッドを表示する。上段に5,000円・1,000円・2,000円のショートカット、数字キーと削除キーを配置し、端末標準キーボードは開かない。金額の右に入力中を示す細い縦線を表示し、全桁を削除した場合は0を表示する。
- ホーム左上のアカウントアイコンは表示しない。
- カレンダーは選択した月度の調整済み開始日から次月度の調整済み開始日前日までを表示する。月をまたぐ日付も同じカレンダーで確認・入力・編集でき、月の切り替わりを日付の月／日表記で示す。

## カレンダー画面
- 下部ナビゲーションの[カレンダー]から遷移する
- デザインはモダンなデザイン
- カレンダー背景はグラフ上部と同じ `#017AF4` の単色とし、グラデーションや雲色は重ねない
- カレンダーに各日付にその日使った合計金額を表示
- 日付を押下>>カレンダーの下に、その日使った金額のリストが表示。
- リストの金額を押下すると支出入力ボトムシートで編集できる。編集後の保存ではカレンダーに戻り、同じ日付の一覧を更新する。
- リストの支出を左へスワイプすると削除アイコンを表示し、押すとその支出を削除して日別合計・残額・グラフを更新する
- 支出行のタップは編集、横スワイプは削除操作として区別する。スワイプしただけで編集画面を開かない。通常時は白い行と細い区切り線を保ち、横スワイプ中と開いた状態だけ淡いベージュの丸い一体形にする。行末の「…」は表示しない。削除操作は赤い丸いボタンに白い円とマイナス記号を用いる。行は指に追従し、戻すときは位置・色・角丸・余白・区切り線を同じ進捗で約0.2秒かけて通常形へ戻す。モーション低減設定では即時に切り替える。
- スライドで月変更
- 月度見出しは「2026年 10月」の順に表示し、横の下向き矢印は置かない。
- 月度表示を押すと年（2026〜2030年）と月を直接選べる。2026年12月から2030年12月まで支出を登録できる。未作成月度は表示・記録時に予算0円で作成する。祝日データが未公表の将来年は暫定的に土日のみを調整する。
- 月度選択を含むすべてのボトムシートは、背景の暗幕をフェードで表示し、シート本体を下からせり上げる。Expo版では閉じる際も逆方向に動かす。動きを減らす設定ではシートの移動を省く。他画面からカレンダーへ移動した直後は、下部の白い支出欄を初めから確保し、データが読み込まれるまで欄内の内容だけを非表示にする。

## グラフ画面

- 下部ナビゲーションの[グラフ]から遷移する
- 上部にグラデーションを使わない `#017AF4` 単色のやりくり金額サマリー、下部に白いグラフ面を連続して配置する
- 上部サマリーの右下に、今月使える金額画面と同じ犬の透過画像を大きく配置する。犬は下端で手足が少し見切れる位置にし、左側の月・金額を隠さない。見出し・月・金額はグラフ画面全体のサイズ感に合わせて読みやすくする。
- 上部サマリーは見出し・月・金額と犬を少し上寄せにして上側の余白を抑える。大きな金額もフォントサイズを変えずに1行で表示し、表示幅を超える場合は金額を横方向に確認できる。選択月のカードは桁数に合わせて幅を広げ、左右端で切れないようにする。
- 各月のやりくり金額をホームの操作色と同じブルーの棒グラフで表示する。棒の色は月で変えない
- 予算未設定の月度は0円として表示し、棒を立てない。設定済み月度の残額のみをその月の棒に反映する
- 中央の[2026年▼]は44px以上の年選択ボタンとし、2026年から2030年までをボトムシートに表示する
- 選択月と金額は棒の中心に追従する一体型の青いカードで表示し、端の月ではカードが画面外へ切れないよう内側へ収める
- React Native版ではグラフの横幅を初回描画時から画面幅に合わせ、月の選択線とカードが遷移直後に隣の月から移動して見えないようにする
- カードから選択した棒へ細い薄グレーの縦線をつなげ、棒の選択状態を示す
- 単位はY軸の上部に置き、年表示・選択カード・グラフの間に大きな空白を作らない
- 棒グラフの縦幅を少し抑え、横軸の月ラベルと下部メニューバーの間には余白を確保する
- 数値はSF Pro Rounded系（Webは `ui-rounded`、Expoは `ui-rounded`）を使用し、太さは基本600で統一する。棒はキーボード操作とスクリーンリーダーで選択できる
- 選択中の[グラフ]タブは淡いブルーの背景で強調する

- 「入力する」でホーム上に支出入力ボトムシートを表示する。「支出を入力」は上部中央へ小さく置き、説明、必須・任意表示、アイコン、金額ラベル、金額の囲みは置かない。中央の金額をタップしたときだけ専用キーパッドを下部へ展開し、メモと保存を表示する。メモをタップしたら専用キーパッドを閉じて端末キーボードに切り替え、金額へ戻る際は端末キーボードを閉じる。キーボードの切り替えでシート全体を押し上げない。閉じる、背景タップ、Esc、保存で閉じます。
- React Native版では金額入力中に金額の右へ細い縦線を表示する。支出入力シート全体は指でスクロールさせない。
- 支出入力シートを閉じると入力内容を破棄し、フォーカスを元のボタンへ戻します。保存・再計算・通信はしません。
- 下部のグラフタブとカレンダータブは各画面へ、ホームタブはホーム画面へ切り替えます。設定アイコンは設定ボトムシートを開きます。ホームのアカウント、当月選択、横スワイプ操作はありません。
- PCでは390pxの端末幅プレビュー、スマホでは全幅表示。390×844pxを基準とし、短い画面や文字拡大時は縦スクロールで内容を維持します。
- UIの数値・文字はHTMLで描画し、参考画像そのものを画面背景として使用しません。
- 犬のエリアは、添付の淡いピンク・アプリコット・イエローのグラデーションをCSSで再現する。右下の透かし・ロゴは含めない。
- 犬の足元には白い楕円形の地面を重ね、グラデーション背景と残高情報の境目をやわらかく整える。

参照と判断の詳細は [REFERENCE_LOCK.md](REFERENCE_LOCK.md)、生成素材の詳細は [ASSET_PROMPTS.md](ASSET_PROMPTS.md) を参照してください。

## 支出入力ボトムシートの再構築

## 下部タブバー

- ホーム・カレンダー・グラフの3項目を画面下端へ固定し、各項目を同じ幅のタップ領域にする。
- 半透明の白い面に18pxの背景ぼかしを適用し、スクロールするコンテンツの色が控えめに透けるようにする。
- 各項目はアイコンを上、短いラベルを下に置き、列全体を操作可能にする。
- 選択中はアイコンとラベルの両方を `#1E90FF`、未選択はグレーにする。選択中は必ず1項目のみとし、Webでは `aria-current="page"` を付与する。
- 透明度を減らす設定では不透明な白背景へ切り替える。
- React Native版では、ホームの空画像、カレンダーの青と桃色の背景、グラフ上部の青と桃色の背景を、それぞれステータスバー背後から同じ一枚のレイヤーで描く。上端に白い帯や色の境目を作らない。下端のホームインジケーター周辺は白にし、入力ボタン・カレンダーの記録・グラフの月ラベルがタブバーに隠れない高さへ調整する。
- React Native版のホーム・カレンダー・グラフは画面全体を指で引っ張っても動かさない。カレンダーで一日の記録が多い場合は、記録一覧の内側だけスクロール可能にする。
