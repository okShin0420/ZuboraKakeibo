# ズボラ会計簿

> 入力は金額だけ。  
> がんばらなくても続けられる、月のやりくりに特化した超ミニマル家計簿アプリ。

## 概要

「ズボラ会計簿」は、家計簿をつけること自体を目的にせず、**「今月あといくら使えるか」を簡単に把握すること**に特化した家計簿アプリです。

一般的な家計簿アプリにある細かなカテゴリ分けや複雑な入力をなくし、基本的には**金額を入力するだけ**で支出を記録できます。

支出が多い日があっても責めるような表現は使わず、ゆるく前向きなフィードバックを提供します。

将来的にはレシートや購入品の写真から支出を自動記録し、**「家計簿を入力する」という作業そのものをなくすこと**を目指します。

## コンセプト

### 「家計簿をちゃんとつける」をやめる

ズボラ会計簿では、詳細な家計管理よりも「続けられること」を重視します。

- 入力の手間を極限まで減らす
- 月のやりくり額だけを管理する
- カテゴリ分けをしない
- 使いすぎても怒らない
- カレンダーでざっくり振り返る
- 残り予算から今後のペースを教える
- 月末にゆるく振り返る
- 将来的には写真だけで記録を完了する

## MVP

初期リリースでは、以下の機能を実装します。

### 1. 月のやりくり額設定

ユーザーが1か月で自由に使える金額を設定します。

設定項目：

- 今月のやりくり額
- 月初通知 ON / OFF
- 月度の開始日
- 土日祝の自動調整 ON / OFF

月度の開始日は1〜31日から選べます。存在しない日付は月末へ丸めます。土日祝の自動調整が有効な場合は開始日を**直前の平日**へ調整し、次月度の調整済み開始日の前日を前月度の終了日として、月度間に空白を作りません。

### 2. 支出記録

支出記録では入力項目を最小限にします。カテゴリ入力は設けません。

#### 必須項目

- 金額

#### 任意項目

- メモ

#### 基本フロー

1. 「入力する」をタップ
2. 金額を入力
3. 保存
4. 残り予算へ即時反映

### 3. ホーム

アプリを開いたときに「今月あといくら使えるのか」がすぐ分かる画面にします。

主な表示：

- 今月の残り予算
- 今日使った金額
- 残り日数
- ゆるいフィードバック
- 「入力する」ボタン

残り予算を画面中央に大きく表示し、情報量を増やしすぎないシンプルなUIを目指します。

ホームには1日あたりの目安を表示しません。画面構成と実装時の優先仕様は [デザイン仕様](docs/design/DESIGN.md) にまとめています。

### 4. カレンダー

カレンダー上に日ごとの支出合計を表示します。日付をタップすると、その日に記録した支出を確認できます。

```text
9月

月   火   水   木   金   土   日
     1    2    3    4    5    6
   ¥800      ¥1,200

7    8    9   10   11   12   13
¥500     ¥3,200
```

## 将来構想

- レシート写真から支出を自動記録する
- 購入品の写真から支出を自動記録する
- 月末のやりくりを、責めない言葉でゆるく振り返る
- 手入力を減らし、最終的には「家計簿を入力する」作業そのものをなくす

## 現在の画面とAPI接続

上記 MVP はプロダクトの目標です。現在の実装は **ホーム画面・支出入力ボトムシート・カレンダー画面・グラフ画面・設定画面・今月使える金額設定画面**をSpring Boot REST APIへ接続しています。月度の自動繰り越しなどは未実装で、MVP全体の完成ではありません。

- React・TypeScript・Vite、lucide-react を使用。
- DBが空の場合は初期予算入力を表示し、保存後に現在月度を作成します。設定済みなら保存済みの予算・支出を表示します。
- 犬の吹き出し・呼吸・まばたき・軽い首かしげ。動きを減らす設定に対応。
- 「入力する」で支出入力ボトムシートが開きます。中央の金額をタップすると専用キーパッドが現れ、閉じるボタン、背景タップ、Esc、金額入力後の「保存する」で閉じられます。
- 「保存する」で支出をSQLiteへ保存し、ホームの残額・今日の支出へ反映します。通信エラー時は入力を保持します。
- 上部中央に当月、右に設定を表示します。アカウントアイコンと月の選択操作はありません。
- 下部の「グラフ」で保存済み月度の年別やりくり金額を表示します。棒で月を選択できます。
- 下部の「カレンダー」で日ごとの支出額を確認できます。左右ボタンで月度を切り替え、設定した月度範囲内の日付をタップすると支出リストが表示されます。期間外はグレースケールで操作できません。リストをタップすると、支出入力ボトムシートで金額とメモを編集できます。
- 右上の設定アイコンから、ホーム上に重なる設定ボトムシートを開きます。月初通知、月度の開始日、土日祝の自動調整を操作でき、今月度・次月度の範囲を確認できます。
- 「今月使える金額」から専用ボトムシートへ切り替え、画面内の数値キーパッドで金額を入力できます。保存するとSQLiteに永続化し、ホームの残り予算へ反映します。
- 芽、カテゴリ、1日あたりの目安、写真入力はありません。

## データベース方針

- 今回の開発ではSpring BootからSQLiteへ保存し、PostgreSQLは使用しません。
- UUIDと日時はアプリケーション側で生成し、SQLiteのDB固有生成関数には依存しません。
- ReactはSpring Boot REST API経由でSQLiteのデータを読み書きします。開発時はViteの`/api`プロキシを使用します。契約は[API設計書](docs/architecture/API_DESIGN.md)を参照してください。
- Spring Boot + SQLiteの起動基盤、Flywayマイグレーション、Entity、DAO、Service、REST Controllerを `backend/` に用意しています。
- 詳細は [データベース設計書](docs/database/DATABASE_DESIGN.md) を参照してください。

### 起動方法

Node.js 22.12 以上と npm を用意してください（[Vite の動作要件](https://vite.dev/guide/)）。

```sh
cd frontend
npm ci
npm run dev
```

プレビュー：<http://127.0.0.1:5173>（このPC内のみ）。停止は実行したターミナルで Ctrl+C。

フロントの起動前に別ターミナルで`backend/`の`mvn spring-boot:run`を実行してください。開発プレビューは<http://127.0.0.1:5173>です。`npm run build`後の`npm run preview`はViteのAPIプロキシを使わないため、別途API接続先を設定した環境で利用してください。

この作業環境では Node.js が未導入だったため、公式配布のポータブル版を `.tools/node-v22.23.2-win-x64` に配置しています。システム設定は変更していません。PowerShell で利用する場合：

```powershell
$env:PATH = "$PWD\.tools\node-v22.23.2-win-x64;" + $env:PATH
Set-Location frontend
npm.cmd run dev
```

### 検証

```sh
cd frontend
npm run typecheck
npm run build
npm test
```

ブラウザテストはインストール済みのMicrosoft Edgeを使用し、API応答をテスト内で模擬します。320px・390px・PC表示、初回登録、支出・設定・予算の保存と再表示、フォーカス、操作領域、動きを減らす設定を確認します。

今回の結果と画面キャプチャは [検証記録](docs/design/QA.md) を参照してください。
